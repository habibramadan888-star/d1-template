# Owner Overview Comparison Rules

| Comparison | Rule |
|---|---|
| Current month | Month-to-date from Dubai month start through today |
| Last month | Previous month, same elapsed day count |
| Same month last year | Same month last year, same elapsed day count |
| Current quarter | Quarter-to-date from Dubai quarter start through today |
| Last quarter | Previous quarter, same elapsed day count |
| Same quarter last year | Same quarter last year, same elapsed day count |

If a source period has no data, display no-data status. Do not generate fake trends.
