## Global Gate Rules

- AED legacy amount converted to fils must have a 0 fils delta against stored `*_fils`.
- Three-decimal values must fail.
- `NaN`, `Infinity`, empty required strings, and unsafe numbers must fail.
- Frontend totals are never reconciliation authority.
- Active reconciliation excludes rows where `voided_at IS NOT NULL`.
- `include_voided` is audit-only and must not feed active dashboard or handover totals.
- Dashboard totals must match backend totals helper before owner-facing switch.
- Production migration requires a dry-run report on a production copy or approved staging snapshot.
- Dry-run scripts must not write database rows.
- Backfill requires a discrepancy report before execution.
