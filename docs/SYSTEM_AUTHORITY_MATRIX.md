# System Authority Source of Truth Matrix

Scope: static architecture audit only. No deploy, no D1 write, no migration, no business formula change, and no secret inspection was performed.

Evidence reviewed:

- `deploy-worker/src/index.js`: auth, `/api/me`, route guards, logout, `/api/history`.
- `deploy-worker/public/portal.html`: three-door entry UI and submit/logout behavior.
- `deploy-worker/public/employee-v3.html`: employee auth bootstrap and identity display.
- `deploy-worker/public/index-51-main.js`: owner shell, read-only admin UI, history loading.
- `modules/auth/tenant-claims.mjs`: target tenant/property/permission claim helper.
- `modules/finance/*.mjs`, `migrations/local/*.sql`, `scripts/audit-*.mjs`: money, receivables, audit readiness evidence.

## Exit Standard

1. Every domain above has an observable current state and target state.
2. Every gap is testable by source scan, API check, or read-only smoke.
3. Every fix item is assignable to auth, backend, finance, QA, or deployment owner.
4. Risk level orders work as: CRITICAL, HIGH, MEDIUM, LOW.
5. Production remains `PRODUCTION_NO_GO`.
