## Column Policy

- Do not add `corp_id` in this draft while legacy `corpid` remains present; a
  duplicate name would create two potential tenant authorities.
- Do not add `tenant_id` in this draft without a reviewed tenant registry.
  Current `tenant_card_id` is a snapshot identifier, not a SaaS tenant id.
- Add only nullable compatibility columns.
- Do not delete or rewrite legacy `corpid`.
- Do not backfill values in the schema migration task.
