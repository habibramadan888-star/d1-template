## Authority Rules

1. Frontend submitted totals are comparison input only, never accounting authority.
2. Backend recomputed totals are the future handover authority.
3. Idempotency key plus canonical fingerprint prevents repeated financial writes.
4. Same idempotency key with same payload returns replay/already accepted.
5. Same rows with a different idempotency key must produce duplicate-risk evidence.
6. Voided rows are rejected from active handover commit.
7. All amount handling must use money helper / backend totals helper in integer fils.
8. Live switching waits for P0-002C or later after human review and staging rehearsal.
