# Unified Login Copy Review

Date: 2026-05-28, Asia/Dubai

## Final Copy

| UI Element          | Copy                                                                        | Reason                                                                          |
| ------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Title               | `Homelink 登录`                                                             | Keeps one product login, not separate owner/employee login pages.               |
| Subtitle            | `UNIFIED SIGN IN`                                                           | Keeps the employee login bilingual visual pattern.                              |
| Account label       | `员工编号 / 管理账号`                                                       | Supports staff IDs and owner/admin authorized login without implying two pages. |
| Account placeholder | `员工填写编号；老板可留空`                                                  | Explains current behavior briefly.                                              |
| Password label      | `密码 / PIN`                                                                | Covers owner password and employee PIN in one form.                             |
| Primary button      | `登录 / SIGN IN`                                                            | Matches original employee login button style.                                   |
| Helper card         | `员工输入编号和 PIN；老板/管理员按授权方式登录。登录后由后端角色自动跳转。` | Clear, single-entry, and role-routing focused.                                  |

## Removed Concept

The copy does not say “owner login page”, “employee login page”, “separate
login”, or “choose a login entrance”. The only product entry is
`unified-login.html`.
